# Thai Law RAG API — คู่มือสำหรับผู้เรียกใช้

ระบบถาม-ตอบประมวลกฎหมายที่ดิน พ.ศ. ๒๔๙๗ · ทุก endpoint อยู่ใต้ `/v1`

---

## เริ่มใช้

```bash
curl -N http://<host>:8000/v1/chat \
  -H "X-API-Key: <คีย์ที่ได้รับ>" \
  -H "Content-Type: application/json" \
  -d '{"question":"ที่ดินที่ออกใบจองห้ามโอนภายในกี่ปี"}'
```

- ทุก endpoint ยกเว้น `/health` ต้องส่ง header **`X-API-Key`**
- คีย์ผิด/ไม่ส่ง → `401`

---

## Endpoints

| Method | Path | ทำอะไร |
|---|---|---|
| `GET` | `/health` | เช็คว่าระบบยังอยู่ — **ไม่ต้องใช้คีย์** |
| `GET` | `/v1/groups` | รายชื่อกลุ่มเอกสาร (ฉบับใช้บังคับปัจจุบัน / ฉบับย้อนหลัง / ...) |
| `GET` | `/v1/years` | ปีเอกสารที่มีในระบบ |
| `GET` | `/v1/models` | รุ่น LLM ที่เลือกได้ |
| `POST` | `/v1/chat` | **ถามคำถาม** — ตอบแบบสตรีม (SSE) |
| `POST` | `/v1/feedback` | ส่ง 👍 / 👎 กลับมา |

## `POST /v1/chat`

### Request

```json
{
  "question": "ที่ดินที่ออกใบจองห้ามโอนภายในกี่ปี",
  "history": [],
  "auto_group": true,
  "groups": null,
  "years": null,
  "model": null
}
```

| ฟิลด์ | ชนิด | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `question` | string | **จำเป็น** | 1–2000 ตัวอักษร |
| `history` | array | `[]` | คำถามต่อเนื่อง — `[{"role":"user"\|"assistant","content":"..."}]` สูงสุด 20 รายการ · ⚠️ ดูข้อควรรู้ด้านล่าง |
| `auto_group` | bool | `true` | ให้ระบบเลือกกลุ่มเอกสารเอง (แนะนำ) |
| `groups` | array\|null | `null` | ระบุกลุ่มเอง — ใช้เมื่อ `auto_group=false` |
| `years` | array\|null | `null` | กรองปีเอกสาร |
| `model` | string\|null | `null` | ต้องเป็นค่าที่อยู่ใน `/v1/models` ไม่งั้น `400` |

### Response — Server-Sent Events

`Content-Type: text/event-stream` · แต่ละบรรทัดคือ `data: {json}\n\n`

```
data: {"stage": "แตกคำถามเป็นหลายมุมค้นหา"}
data: {"meta": {"groups": [...], "n_sources": 12, "retrieval_mode": "hybrid", "search_q": ""}}
data: {"token": "ตามมาตรา ๓๑ "}
data: {"token": "ที่ดินที่ออกใบจอง..."}
data: {"final": {"answer": "...", "chunks": [...], "groups_used": [...],
                 "retrieval_mode": "hybrid", "elapsed": 18.4}}
```

| event | ใช้ทำอะไร |
|---|---|
| `stage` | ข้อความความคืบหน้า เอาไว้โชว์ระหว่างรอ (คำถามหนึ่งใช้ 15–60 วินาที) |
| `meta` | ข้อมูลประกอบ มาก่อนคำตอบ |
| `token` | ชิ้นส่วนคำตอบ — ต่อกันเองฝั่ง client |
| `final` | คำตอบเต็ม + แหล่งอ้างอิง |
| `error` | เกิดปัญหากลางคัน สตรีมจบเท่านี้ |

> `final.answer` คือคำตอบเต็มอยู่แล้ว — ถ้าไม่อยากทำ streaming UI จะรอ `final` อย่างเดียวก็ได้

---

## ⚠️ `retrieval_mode` — ต้องดูทุกครั้ง

| ค่า | แปลว่า |
|---|---|
| `hybrid` | ปกติ — ค้นด้วยความหมาย + คำสำคัญ |
| `bm25_only` | **ระบบค้นด้วยความหมายใช้ไม่ได้ชั่วคราว** ค้นด้วยคำสำคัญอย่างเดียว |

โหมด `bm25_only` ยังตอบได้ แต่**แม่นน้อยลง** โดยเฉพาะเมื่อผู้ใช้ใช้คำต่างจากตัวบท
(ถาม *"บุกรุก"* แต่กฎหมายเขียน *"เข้าไปยึดถือครอบครอง"*)

`final.answer` จะมีป้ายกำกับมาให้แล้ว แต่**ควรแสดงเตือนใน UI ด้วย**

## ข้อควรรู้ก่อนใช้งานจริง

### 1. `history` ยังไม่เคยวัดผล
ระบบมีชุดคำถามวัดผล 120 ข้อ ได้ **99/100** — แต่**ทั้งหมดเป็นคำถามเดี่ยว**
การคุยต่อเนื่องหลายเทิร์นใช้งานได้ แต่ยังไม่มีตัวเลขรับประกัน

### 2. รับได้ทีละคำขอ
reranker ใช้ GPU ตัวเดียว → รัน **worker เดียว** ยิงพร้อมกันหลายคำขอจะช้าลงมาก
ถ้าต้องรับโหลดจริง ควรทำคิวฝั่งผู้เรียก

### 3. คำถามหนึ่งใช้ 15–60 วินาที
ตั้ง timeout ฝั่ง client อย่างน้อย **120 วินาที** และใช้ `stage` โชว์ความคืบหน้า

### 4. บูตครั้งแรกช้า
เซิร์ฟเวอร์ใช้เวลา ~1 นาทีก่อนพร้อม — เช็คด้วย `/health` ก่อนยิงจริง

### 5. ตอบจากเอกสารเท่านั้น
ถ้าคำตอบไม่มีในเอกสาร ระบบจะบอกว่าไม่พบ — **ไม่แต่งขึ้นมาเอง** (วัดด้วยคำถามหลอก 12 ข้อ ผ่านทั้งหมด)

## รหัสข้อผิดพลาด

| รหัส | ความหมาย |
|---|---|
| `401` | คีย์ผิดหรือไม่ได้ส่ง |
| `400` | `model` ที่ระบุไม่มีในระบบ |
| `422` | ข้อมูลไม่ถูกรูปแบบ (คำถามว่าง, `role` ไม่ใช่ user/assistant, ...) |
| `500` | ข้อผิดพลาดภายใน — รายละเอียดอยู่ใน log ฝั่งเซิร์ฟเวอร์ |

## เรื่องเวอร์ชัน

ทุก endpoint อยู่ใต้ `/v1` เพราะเมื่อมีคนใช้แล้ว รูปแบบข้อมูลจะกลายเป็นสัญญา

```
เพิ่มฟิลด์ใหม่              ทำได้ ของเดิมไม่พัง
เปลี่ยนชื่อ / ลบ / เปลี่ยนชนิด   จะเปิด /v2 แทน แล้วคง /v1 ไว้ พร้อมแจ้งล่วงหน้า
```

**ฝั่งผู้เรียกควรอ่านเฉพาะฟิลด์ที่ใช้ และไม่พังเมื่อเจอฟิลด์ที่ไม่รู้จัก**

## ตัวอย่าง Python

```python
import json, httpx

with httpx.stream(
    "POST", "http://<host>:8000/v1/chat",
    headers={"X-API-Key": "<คีย์>"},
    json={"question": "ใครมีอำนาจเพิกถอนโฉนดที่ดิน"},
    timeout=120,
) as r:
    r.raise_for_status()
    for line in r.iter_lines():
        if not line.startswith("data: "):
            continue
        ev = json.loads(line[6:])
        if "token" in ev:
            print(ev["token"], end="", flush=True)
        elif "final" in ev:
            print("\n\nอ้างอิง:", len(ev["final"]["chunks"]), "ตัวบท")
            if ev["final"]["retrieval_mode"] == "bm25_only":
                print("⚠️ ค้นได้ไม่เต็มความสามารถ ควรตรวจซ้ำ")
        elif "error" in ev:
            print("\n[error]", ev["error"]["detail"])
```
